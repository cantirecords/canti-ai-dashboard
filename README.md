# Canti AI Dashboard

![Canti AI](https://cdn-icons-png.flaticon.com/512/4712/4712038.png)

The intelligent conversational AI platform for automating customer interactions, lead qualification, and sales.

## Features

- **Smart Conversations**: Natural language processing that handles context and intent.
- **Real-time Inbox**: Unified messaging interface for WhatsApp, SMS, and Webchat.
- **Lead Management**: Kanban-style tracking for leads and sales pipelines.
- **Deep Analytics**: Insights into response times, conversion rates, and volume.
- **Expert Panel**: Built-in AI assistant ("Ask CANTI") to help manage the dashboard.

## Tech Stack

- **Frontend**: React 19, Vite, TypeScript, Tailwind CSS
- **Backend / Auth**: Supabase
- **Icons**: Material Symbols
- **Fonts**: Inter (Google Fonts)

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/canti-ai-dashboard.git
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Environment Setup**
   Create a `.env` file with your Supabase credentials:
   ```env
   VITE_SUPABASE_URL=your_project_url
   VITE_SUPABASE_ANON_KEY=your_anon_key
   ```

4. **Run the development server**
   ```bash
   npm run dev
   ```
